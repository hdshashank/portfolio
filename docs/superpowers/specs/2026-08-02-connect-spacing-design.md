# Connect spacing adjustment

## Scope

Tighten the approved Connect section without changing its content, hierarchy, links, colors, typography, or signature bottom crop.

## Design

- Reduce the section's responsive minimum height from `470–620px` to `390–500px`.
- Retain a deliberate flexible gap between the contact overview and closing wordmark.
- Center the `SHASHANK H D` wordmark at every viewport width.
- Keep the name bottom-cropped and keep `H D` on its own line on narrow screens.

## Validation

- Confirm the wordmark remains centered at desktop and mobile breakpoints.
- Confirm no horizontal overflow is introduced.
- Run type checking and the production build.
